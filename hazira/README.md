# הזירה

**משחק דו־קרב** בסגנון הזירה (כאן 11 / הפורמט ההולנדי *The Floor*): שניים,
ראש בראש, כל אחד מהטלפון שלו. מופיעה תמונה — אתם אומרים בקול מה רואים,
והטלפון מאזין בלייב ומכריע בזמן אמת.

```
טלפון א'                    טלפון ב'
┌──────────┐                ┌──────────┐
│ ⏱ 45.0    │   ⇄  שרת  ⇄   │ ⏱ 38.2    │
│  🖼 תמונה  │                │  🖼 תמונה  │
│ 🎤 מאזין   │                │  התור שלו │
└──────────┘                └──────────┘
```

אחד פותח דו־קרב ומקבל קוד, השני סורק QR או מקליד אותו. כל אחד בוחר קטגוריה —
ו**נלחמים בקטגוריה של היריב**. בסוף אפשר סיבוב נוסף, שבו התפקידים מתחלפים
והקטגוריה השנייה נכנסת.

> יש גם **משחק הזירה המלא** על לוח משבצות לקבוצה גדולה — כיבוש טריטוריות,
> בחירת יריב גובל והדחות. הקישור אליו בתחתית דף הבית. פרטים בהמשך.

## לשחק מול מישהו שלא נמצא איתכם

צריך כתובת ציבורית, כי הכתובת המקומית של המחשב לא נגישה מחוץ לבית.
הדרך המהירה היא מנהרה:

```bash
npm install
npm run play        # דורש cloudflared מותקן
```

זה מדפיס כתובת כמו `https://brave-horse-42.trycloudflare.com`. פותחים
אותה, לוחצים **"פתיחת דו־קרב"**, ואז **"שליחת הזמנה"** — בטלפון זה פותח
את תפריט השיתוף (וואטסאפ, הודעות), ובמחשב מעתיק את הקישור ללוח. היריב
פותח את הקישור, ממלא שם ובוחר קטגוריה. זהו.

התקנת cloudflared: `brew install cloudflared` (macOS),
`winget install Cloudflare.cloudflared` (Windows), או
[שחרורים](https://github.com/cloudflare/cloudflared/releases) (Linux).
הכתובת חיה כל עוד החלון פתוח, ומשתנה בכל הרצה.

### כתובת קבועה

להעלאה לשרת מתארח (Render, Railway, Fly) צריך שירות Node יחיד שתומך
ב-WebSocket, עם `npm install` ו-`npm start`. הכתובת נגזרת אוטומטית
מכותרות הבקשה, כך שאין מה להגדיר; אם בכל זאת יוצא קישור שגוי, אפשר
לכפות `PUBLIC_URL=https://הכתובת-שלכם`.

מצב המשחק נשמר בזיכרון, ולכן צריך מופע אחד — לא כמה עותקים במקביל.

## שני מכשירים באותו בית

כששניכם על אותה רשת Wi-Fi אפשר בלי מנהרה — צריך מחשב אחד שמריץ את השרת.

**על המחשב:**

```bash
npm install         # מייצר גם את חבילות התוכן והתמונות
npm run cert        # תעודה מקומית — בלעדיה המיקרופון בטלפונים ייחסם
npm start
```

ההרצה מדפיסה את הכתובת שאליה הטלפונים צריכים להיכנס, למשל:

```
  פתחו בשני הטלפונים:  https://192.168.1.24:3000
```

**על טלפון א׳:** פותחים את הכתובת הזו. בכניסה הראשונה יופיע מסך אזהרת
אבטחה — זו התעודה המקומית שלכם. בכרום: "מתקדם" ← "המשך אל…"; בספארי:
"הצג פרטים" ← "בקר באתר". מאשרים פעם אחת, ואז לוחצים **"פתיחת דו־קרב"**,
ממלאים שם ובוחרים קטגוריה. מופיע קוד QR.

**על טלפון ב׳:** סורקים את ה-QR מהמצלמה (או מקלידים את הכתובת ואת הקוד
בן ארבע האותיות). מאשרים גם כאן את אזהרת האבטחה, ממלאים שם ובוחרים
קטגוריה.

כששני הטלפונים בפנים, מי שלוחץ **"מוכנים — מתחילים"** פותח. מכאן: לוחצים
"הפעלת מיקרופון" פעם אחת ומאשרים את הבקשה, ומשחקים.

### אם משהו לא עובד

| התסמין | מה לעשות |
|---|---|
| הטלפון לא מצליח להתחבר בכלל | ודאו שהוא על אותה רשת Wi-Fi ולא על סלולר. בדקו שחומת האש של המחשב לא חוסמת את פורט 3000. |
| הכתובת שהודפסה לא נענית | למחשב יש כמה כתובות (Docker, VPN). ההרצה מציעה חלופות בסוף הפלט — הריצו `HOST_IP=<כתובת אחרת> npm start`. |
| היריב לא באותה רשת | זה המצב של "לשחק מול מישהו שלא נמצא איתכם" למעלה — צריך מנהרה. |
| כפתור המיקרופון לא עושה כלום | ודאו שנכנסתם ב-`https` ושאישרתם את התעודה. פיירפוקס לא תומך בזיהוי דיבור — השתמשו בכרום או בספארי. תמיד אפשר להקליד במקום. |
| המיקרופון עובד אבל לא מזהה | רעש רקע או מבטא. מד ההתאמה מראה מה נשמע; אם זה לא מתקרב, הקלידו. |
| המסך ננעל והחיבור נפל | הטלפון מתחבר מחדש לבד וזוכר את המקום. אם לא — רענון מספיק. |

> **למה צריך תעודה?** דפדפנים מאפשרים גישה למיקרופון רק בהקשר מאובטח.
> `localhost` נחשב מאובטח, אבל `http://192.168.x.x` לא. `npm run cert` יוצר
> תעודה חתומה עצמית שמכסה את כתובות ה-LAN של המחשב. בלי תעודה המשחק עדיין
> עובד — פשוט מקלידים תשובות במקום לומר אותן. להרצה מפורשת ב-HTTP: `npm run dev`.

### על מסך גדול (אופציונלי)

אפשר לפתוח את הכתובת גם על טלוויזיה או לפטופ כדי שאחרים יראו את הדו־קרב:
`https://<הכתובת>:3000/board.html?code=<הקוד>`.

## חוקי הדו־קרב

- כל אחד בוחר קטגוריה אחת. הזירה מגרילה מי מאתגר ומי מגן.
- **הדו־קרב מתנהל בקטגוריה של המותקף** — מה שהופך את הבחירה שלך למגן שלך.
- לכל אחד שעון של 45 שניות. רק שעון אחד רץ בכל רגע, והמאתגר מתחיל.
- תשובה נכונה עוצרת את השעון שלכם ומעבירה את התור. ניחושים ללא הגבלה ובלי עונש.
- אפשר לוותר על תמונה, אבל השעון ממשיך לרוץ שלוש שניות עד שמגיעה תמונה חדשה.
- מי שהשעון שלו נגמר ראשון — הפסיד.
- **סיבוב נוסף** מחליף תפקידים, כך שהפעם משחקים בקטגוריה השנייה. התוצאה נצברת.

## משחק הלוח המלא

לקבוצה גדולה על מסך אחד, בדיוק כמו בתוכנית. אותם חוקי דו־קרב, ומסביבם:

- כל מתמודד מקבל טריטוריה רציפה בלוח משבצות.
- הזירה בוחרת מתמודד אקראי; הוא רואה את הקטגוריות של כל מי שגובל בו ובוחר יריב.
- מי שהשעון שלו נגמר מודח, וכל הטריטוריה שלו עוברת למנצח.
- ניצח המאתגר — הוא שומר על הקטגוריה שלו. ניצח המותקף — הוא **יורש** את קטגוריית המאתגר.
- המנצח מחליט אם לתקוף שוב מיד או להחזיר את הבחירה לזירה.
- המשחק נגמר כשנשאר מתמודד אחד.

פתיחה: הקישור בתחתית דף הבית, או `POST /api/rooms` עם `{"config":{"mode":"board"}}`.

## ההאזנה והניתוח

התמלול מהטלפון זורם לשרת תוך כדי דיבור, והשרת מכריע. ההכרעה בעברית עוברת
שלוש שכבות ב-[`server/judge.js`](server/judge.js):

1. **התאמה מדויקת** אחרי נרמול — ניקוד, אותיות סופיות, פיסוק, ואות שימוש
   בתחילת מילה (`הכלב` = `כלב`).
2. **התאמה פונטית** — בליעת שגיאות זיהוי דיבור נפוצות (`ת/ט`, `כ/ק`, `א/ע/ה`,
   `ס/ש`, `ב/ו`) וכתיב מלא/חסר (`עגבניה` = `עגבנייה`).
3. **דמיון מחרוזות** כרשת ביטחון אחרונה, בסף מחמיר כדי ש`אוסטריה` לא תתקבל
   כתשובה ל`אוסטרליה`.

התשובה מזוהה גם כשהיא משובצת בתוך מלמול (`"אהh רגע זה צרפת"`), ומה שנמצא
*קרוב* לתשובה מוצג חי על המסך הגדול כמד התאמה — בלי לזכות בנקודה.

**הכרעה תמיד בצד השרת.** הלקוח לא מקבל את התשובה הנכונה, רק את התמונה.

בסוף כל דו־קרב נאסף דוח: דיוק, זמן תגובה ממוצע, התשובה המהירה ביותר, רצף הכי
ארוך, ויתורים, כמעט־פגיעות, ותשובות שניתנו כשנותרו פחות מחמש שניות על השעון.
זמין גם כ-JSON ב-`GET /api/rooms/:code/report`.

## תוכן משלכם

חבילת ההדגמה נוצרת אוטומטית בהתקנה: 7 קטגוריות, 132 פריטים, כולם SVG שנוצרים
מקומית (דגלים משורטטים בקוד, השאר אמוג'י) כדי שהמשחק ירוץ בלי תלות ברשת.
התוכן שנוצר לא נשמר ב-git; `npm run content` בונה אותו מחדש.

להחלפה בתוכן אמיתי — קובץ JSON אחד לקטגוריה תחת `content/packs/`:

```json
{
  "id": "logos",
  "name": "לוגואים",
  "hint": "איזו חברה?",
  "items": [
    { "image": "/media/logos/acme.png", "answer": "אקמה", "aliases": ["חברת אקמה"] },
    { "text": "1948", "answer": "הכרזת העצמאות" }
  ]
}
```

`image` הוא נתיב שמוגש מ-`content/media/`, או כתובת מלאה. `aliases` הן תשובות
קבילות נוספות. פריט יכול להיות טקסט במקום תמונה.

## מגבלות ידועות

- זיהוי דיבור נתמך בכרום/אדג' (כולל אנדרואיד) ובספארי מ-iOS 14.5. **לא בפיירפוקס.**
  בכל מצב יש שדה הקלדה כגיבוי מלא.
- איכות הזיהוי תלויה במנוע של הדפדפן ובמיקרופון; ברעש רקע כדאי להקליד.
- מצב המשחק נשמר בזיכרון בלבד — הפעלה מחדש של השרת מאפסת חדרים פתוחים.
